## 1. Purpose

This Software Test Plan defines the approach for testing the IT Infrastructure & Asset Management System developed by Team 08. It describes the testing scope, strategy, environment, responsibilities, schedule, test cases and reporting process.

## 2. Scope

Testing will cover the system's agreed requirements for:

- IT asset registration and management.
- Hardware and software information tracking.
- Asset allocation and availability.
- Software license and warranty tracking.
- Maintenance record management.
- Expiry and maintenance alerts, where implemented.
- Input validation and access control, where implemented.

## 3. Testing Approach

Testing will include functional, validation, integration, usability, performance and security checks as applicable to the implemented system and approved requirements.

## 4. Test Case Management

Each test case will have a unique identifier, preconditions, test steps, expected result, actual result, execution status and related SRS requirement ID.

Test outcomes will be recorded honestly as Pass, Fail, Blocked or Not Run.
