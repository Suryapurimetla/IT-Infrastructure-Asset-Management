## 5.3 Tools

The following tools are intended to support the documentation, design, collaboration, and development activities for the IT Infrastructure & Asset Management System.

| Tool | Purpose | Usage in the Project |
|---|---|---|
| Git | Version control system. | Tracks changes to project files and supports collaboration. |
| GitHub | Repository hosting and collaboration platform. | Stores project documentation and source code and supports branches, commits, and pull requests. |
| Draw.io (diagrams.net) | Diagramming tool. | Creates and edits the UML component diagram and other architectural diagrams. |
| Mermaid | Diagram description and rendering tool. | Creates sequence diagrams within Markdown documentation. |
| Markdown | Lightweight documentation format. | Organizes the SAD, SRS, STP, and related project documents. |
| Web Browser | Application access and documentation viewing tool. | Used to access GitHub, view documentation, and access the application if implemented as a web application. |
| Text Editor or IDE | Software development and editing environment. | Used to create and maintain documentation and, when development begins, source code. |

### Tool Selection Considerations

The selected tools should be accessible to the project team and suitable for the project's academic scope and timeline. Version control should be used to track meaningful changes, while diagrams and documentation should be kept consistent with the final requirements and implementation.

The exact development environment, programming language, framework, database, and testing tools should be added to this table once they are confirmed by the team.

This list describes tools intended or used for project activities. The team should remove any tools that were not actually used and update the list to reflect the final project setup.
