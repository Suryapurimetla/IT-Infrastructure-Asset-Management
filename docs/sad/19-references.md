## 5.2 References

The following documents and resources are relevant to the architecture and design of the IT Infrastructure & Asset Management System.

### 5.2.1 Project Documents

1. **Software Requirements Specification (SRS):** Team 08, *IT Infrastructure & Asset Management System*. Defines the functional, non-functional, and security requirements for the project.
2. **Software Test Plan (STP):** Team 08, *IT Infrastructure & Asset Management System*. Describes the planned testing approach, test cases, test environment, and verification activities.
3. **Requirements Traceability Matrix (RTM):** Team 08, *IT Infrastructure & Asset Management System*. Maps requirements to planned test cases and supports verification coverage.
4. **Software Architecture and Design Specification (SAD) Template:** Faculty-provided template used to organize this document.

### 5.2.2 Technical References

The following resources may be consulted when finalizing and implementing the system. Retain only the resources actually used by the team.

1. **Mermaid Documentation:** https://mermaid.js.org/ — Reference for creating sequence diagrams in Markdown.
2. **diagrams.net (Draw.io):** https://www.diagrams.net/ — Diagramming tool used to create and edit the UML component diagram.
3. **Git Documentation:** https://git-scm.com/doc — Reference for version control operations.
4. **GitHub Documentation:** https://docs.github.com/ — Reference for repository management, branches, commits, and pull requests.
5. **HTTP Semantics — RFC 9110:** https://www.rfc-editor.org/rfc/rfc9110 — Reference for HTTP methods and status codes used in the proposed API design.

### 5.2.3 Reference Maintenance

The team should update this section if the final implementation uses additional frameworks, libraries, database technologies, or security mechanisms. Any resource listed as a reference should be relevant to the project and should have been consulted or used during the work.
