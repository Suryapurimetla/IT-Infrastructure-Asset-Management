# 1. Introduction

## 1.1 Purpose

This Software Architecture and Design Specification (SAD) describes the architecture and design of the IT Infrastructure & Asset Management System developed by Team 08.

The document defines the system's major components, architectural decisions, interfaces, data management approach, security considerations, and interactions between components. It serves as a reference for developers, testers, and other project stakeholders during implementation, testing, and maintenance.

## 1.2 Scope

The IT Infrastructure & Asset Management System is designed to provide centralized management of an organization's IT assets.

The system's scope includes:

- Registration and management of hardware and software assets.
- Viewing, searching, and updating asset information.
- Asset allocation and availability tracking.
- Software license and warranty information management.
- Maintenance record management.
- Identification of upcoming expiry and maintenance events.
- Input validation and access control, where implemented.

The architecture will organize these functions into appropriate components with clear responsibilities. The final component interfaces and technology choices will be confirmed according to the team's implementation plan.

## 1.3 Audience

The intended audience includes:

- Developers responsible for implementing the application.
- Test engineers responsible for validating system behaviour.
- Project team members responsible for requirements and design.
- IT administrators who manage asset information.
- Project evaluators and course coordinators.
