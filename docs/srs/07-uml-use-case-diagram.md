# 7. UML Use-Case Diagram

The UML use-case diagrams describe the interactions between the users and the IT Infrastructure & Asset Management System. They identify the main actors and the functions available to them.

## 7.1 UML Use-Case Diagram 1: Asset Management

**Actors:**
- IT Administrator
- Staff / Asset User

**Use cases:**
- Register Asset
- View Asset Details
- Search Asset
- Update Asset Information
- Allocate Asset
- Return or Reassign Asset

The IT Administrator manages asset records and allocations. Staff or asset users can view information related to their assigned assets where this functionality is available.

## 7.2 UML Use-Case Diagram 2: License, Warranty and Maintenance Management

**Actors:**
- IT Administrator
- Maintenance Personnel

**Use cases:**
- Manage Software License
- Update Warranty Details
- View Expiry Information
- Record Maintenance Activity
- Update Maintenance Status
- Identify Upcoming Maintenance
- View Relevant Alerts

The IT Administrator manages license and warranty information. Maintenance Personnel record maintenance activities and update maintenance status according to their assigned permissions.

## Diagram Representation

The diagrams should show the actors outside the system boundary and the relevant use cases inside the system boundary. Connect each actor to the use cases they participate in. Use the system name **IT Infrastructure & Asset Management System** as the system boundary label.
