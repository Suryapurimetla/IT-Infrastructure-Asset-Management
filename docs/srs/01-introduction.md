# 1. Introduction

## 1.1 Purpose

This document is a Software Requirements Specification (SRS) for the IT Infrastructure & Asset Management System developed by Team 08. It defines the functional and non-functional requirements, interfaces, and verification criteria of the system. This document serves as a reference for developers, testers, project team members, and evaluators.

## 1.2 Scope

The IT Infrastructure & Asset Management System is designed to maintain and manage an organization's IT assets in a centralized system. It covers hardware and software asset registration, asset information management, asset allocation, license and warranty tracking, maintenance records, and related notifications where implemented.

The system aims to improve asset visibility, simplify tracking, reduce manual record-keeping, and support effective IT asset management. Features outside the agreed project scope, including internal operations of external systems and physical hardware repairs, are excluded.

## 1.3 Audience

The intended audience includes:

- Developers responsible for implementing the system.
- Test engineers responsible for validating the requirements.
- Project team members responsible for design and documentation.
- IT administrators responsible for managing asset records.
- Project evaluators and course coordinators.

## 1.4 Definitions

- **ITAM:** IT Asset Management.
- **SRS:** Software Requirements Specification.
- **SAD:** Software Architecture and Design.
- **STP:** Software Test Plan.
- **FR:** Functional Requirement.
- **NFR:** Non-Functional Requirement.
- **RTM:** Requirements Traceability Matrix.
- **UI:** User Interface.
- **API:** Application Programming Interface.
- **Asset:** An IT resource, such as a computer, monitor, printer, or software license, managed by the system.
