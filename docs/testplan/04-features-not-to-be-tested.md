# 4. Features Not to Be Tested

Testing will be limited to the agreed scope of the IT Infrastructure & Asset Management System. The following items are excluded unless they are explicitly included in the approved Software Requirements Specification (SRS).

## 4.1 Internal Functionality of Third-Party Tools

The internal implementation of external libraries, frameworks and development tools will not be tested. Testing will focus on how the application uses these dependencies.

## 4.2 Operating System Internals

Internal operating system functionality will not be tested as part of this project.

## 4.3 Database Engine Internals

The internal implementation of the selected database engine will not be tested. The application's data storage, retrieval and handling of database errors will be tested where applicable.

## 4.4 External Service Infrastructure

The internal infrastructure of external notification or email services will not be tested. The application's integration with such services will be tested if the integration is implemented and included in the approved requirements.

## 4.5 Physical Hardware Failure Testing

Testing physical hardware failure, device durability and hardware repair procedures is outside the scope of this software project.

## 4.6 Unapproved or Unimplemented Features

Features not included in the approved requirements, and features that are neither implemented nor required for the submission, will not be treated as completed functionality.

Any change to the testing scope must be reviewed and reflected in the relevant project documents.
