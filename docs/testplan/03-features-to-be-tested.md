# 3. Features to Be Tested

The following features will be tested against the approved Software Requirements Specification (SRS). Testing will be performed only for features included in the agreed project scope and available for verification.

## 3.1 Asset Registration

Verify that valid asset details can be entered and saved, and that invalid or incomplete records are handled appropriately.

## 3.2 Asset Identification

Verify that each asset has a unique identifier and that duplicate identifiers are rejected, if uniqueness is required by the SRS.

## 3.3 Asset Search and Retrieval

Verify that users can locate and view asset records using the available search and filtering options.

## 3.4 Asset Updates

Verify that permitted asset details can be updated and that the saved changes are displayed correctly.

## 3.5 Hardware and Software Information

Verify that supported hardware and software details are recorded and retrieved accurately.

## 3.6 Asset Allocation

Verify asset assignment, availability and allocation status according to the approved project rules, where implemented.

## 3.7 License and Warranty Tracking

Verify that license and warranty information is stored correctly and that expiry status follows the defined rules.

## 3.8 Maintenance Records

Verify that maintenance information can be recorded, updated and retrieved for the relevant asset.

## 3.9 Alerts and Notifications

Verify configured license, warranty and maintenance alerts, where implemented.

## 3.10 Input Validation and Error Handling

Verify that invalid inputs produce appropriate messages and do not result in incorrect or incomplete records being saved.

## 3.11 Access Control

Where authentication and permissions are implemented, verify that users can access only the functions permitted by their assigned roles.

## 3.12 Usability and Performance

Verify that common tasks can be completed clearly and that response times satisfy the measurable performance requirements defined in the SRS.

The final test cases will reference the corresponding approved SRS requirement IDs.
