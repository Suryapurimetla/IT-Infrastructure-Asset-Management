# 8. Test Deliverables

## 8.1 Documents and Records

The following deliverables will be maintained by Team 08 during the testing process:

1. Software Test Plan (STP).
2. Test cases and test data.
3. Test execution results.
4. Defect and issue records.
5. Retest and regression testing results.
6. Final test summary report.

## 8.2 Test Execution Records

Each executed test case will record its test case ID, objective, preconditions, test steps, expected result, actual result, execution status, and remarks.

Test cases will be marked as Pass, Fail, or Not Run based on the actual execution results.

## 8.3 Defect Records

Identified defects will be documented with a description, steps to reproduce, expected behaviour, actual behaviour, severity, and current status.

## 8.4 Final Test Report

The final test report will summarize the tests executed, pass and fail counts, unresolved defects, limitations, and overall testing status. Only verified results will be included.
