# 8. Test Deliverables

## 8.1 Documents and Records

The following deliverables will be maintained by Team 08 during the testing process:

1. Software Test Plan (STP).
2. Updated Test Case Document and test data.
3. Test execution results.
4. Defect and issue records.
5. Retest and regression testing results.
6. Unit Test Report.
7. System Validation Report.
8. Code Coverage Report.
9. Branch Coverage Report.
10. Final test summary report.

## 8.2 Test Execution Records

Each executed test case will record its test case ID, objective, preconditions, test steps, expected result, actual result, execution status, and remarks.

Test cases will be marked as Pass, Fail, or Not Run based on the actual execution results.

## 8.3 Defect Records

Identified defects will be documented with a description, steps to reproduce, expected behaviour, actual behaviour, severity, and current status.

## 8.4 Required Testing Reports

The following reports will be maintained in the project's `docs/reports/` directory:

| Report | Purpose |
|---|---|
| Unit Test Report | Records automated test execution results. |
| System Validation Report | Records validation scenarios and observed application behaviour. |
| Code Coverage Report | Summarizes statement coverage results. |
| Branch Coverage Report | Summarizes conditional branch coverage results. |

## 8.5 Final Test Report

The final test report will summarize the tests executed, pass and fail counts, unresolved defects, coverage results, limitations, and overall testing status.

Only verified results will be included in the final reports.
