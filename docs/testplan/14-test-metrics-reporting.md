# 14. Test Metrics and Reporting

## 14.1 Test Metrics

| Metric | Description |
|---|---|
| Total test cases | Total number of documented test cases. |
| Executed test cases | Number of test cases actually executed. |
| Passed test cases | Number of executed cases meeting their expected results. |
| Failed test cases | Number of executed cases not meeting their expected results. |
| Not-run test cases | Number of cases that have not been executed. |
| Test pass percentage | Passed cases divided by executed cases, multiplied by 100. |
| Defects identified | Total number of defects recorded. |
| Open defects | Number of defects that remain unresolved. |

## 14.2 Reporting

The team will maintain test execution records and report significant failures, blocking issues, and testing progress.

The final test report will include test coverage, execution results, unresolved defects, known limitations, and recommendations for further testing.

## 14.3 Result Accuracy

Metrics will be calculated using recorded execution data. Test cases that have not been executed will not be counted as passed. Limitations affecting the completeness of results will be clearly stated.
