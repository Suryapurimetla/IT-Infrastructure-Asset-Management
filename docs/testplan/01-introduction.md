# 1. Introduction

## 1.1 Purpose

The purpose of this Software Test Plan (STP) is to define the testing activities for the IT Infrastructure & Asset Management System developed by Team 08.

This document describes the testing scope, strategy, environment, responsibilities, schedule, test cases and reporting process. Testing will verify whether the implemented features satisfy the approved Software Requirements Specification (SRS).

## 1.2 Scope

Testing will cover the following features, subject to their inclusion in the approved requirements and availability in the implementation:

- IT asset registration and record management.
- Hardware and software information tracking.
- Asset searching, filtering and updating.
- Asset allocation and availability tracking.
- Software license and warranty tracking.
- Maintenance record management.
- License, warranty and maintenance alerts, where implemented.
- Input validation and access control, where implemented.

Testing will focus on features included in the approved project scope.

## 1.4 Definitions and Acronyms

- **ITAM:** IT Infrastructure & Asset Management.
- **SRS:** Software Requirements Specification.
- **SAD:** Software Architecture and Design.
- **STP:** Software Test Plan.
- **FR:** Functional Requirement.
- **NFR:** Non-Functional Requirement.
- **RTM:** Requirements Traceability Matrix.
- **Test Case:** A set of steps, inputs and expected results used to verify a feature.
- **Defect:** A difference between the expected result and actual result of a test.
