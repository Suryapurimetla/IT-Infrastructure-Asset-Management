## 10. Risks and Mitigation

Risk                                               Mitigation

Delay in stable build delivery                     Request early builds from the development team.

Test environment downtime                          Resolve environment and configuration issues before testing.

Insufficient test data                             Prepare sample asset records before test execution.

Incomplete requirements                            Review the SRS and clarify requirements before testing.

Security vulnerabilities                           Test input validation, access control, and data protection.
